# Codex Pet Plus · 펫 위에 남은 한도

**Codex 앱의 기본·커스텀 펫 바로 위에서 남은 Codex 한도를 보여주는 Windows 프로그램**입니다. 앱의 펫 창을 자동으로 찾아 이동을 따라갑니다. 앱 파일 수정, 앱 복사본, WindowsApps 소유권 변경이나 관리자 승인이 필요하지 않습니다.

Windows 10/11 x64용입니다. 표시줄을 사용하는 동안 Pet Plus를 실행해 두세요. 특정 앱 버전 번호로 실행을 제한하지 않으며, 실제 창을 감지하는 방식입니다. OpenAI의 공식 제품은 아닙니다.

## 다운로드와 실행

1. GitHub에 로그인한 뒤 [Windows 빌드 페이지](https://github.com/seoyeonwoo11/Codex-Pet-Plus/actions/workflows/windows-desktop.yml)를 엽니다.
2. 최신 성공한 **main** 실행의 **Artifacts → CodexPetPlus-Windows-x64**를 다운로드하고 압축을 풉니다.
3. 이전 Pet Plus가 실행 중이면 **트레이 아이콘 → 종료**를 선택합니다. 설정 창만 닫으면 계속 실행 중입니다.
4. 새 **CodexPetPlus.exe**를 실행하고 **버전 0.6.0**을 확인합니다. .NET, Node.js, Python은 별도 설치하지 않아도 됩니다.
5. 평소 사용하던 Codex 앱에서 기본 펫이나 원하는 커스텀 펫을 켭니다. **펫 위에 한도 표시**는 처음 실행할 때 기본으로 켜져 있습니다.

설정 창을 닫아도 표시줄은 계속 실행됩니다. 표시줄 우클릭이나 트레이 아이콘에서 설정·한도 새로고침·종료를 선택하세요. 표시줄 켜기/끄기는 즉시 적용하고 저장합니다. 0.5.x의 모드 전용 설정을 사용했더라도 새 표시줄을 기본으로 활성화하며, 0.6.0에서 직접 끈 설정은 다음 실행에도 유지합니다.

## 펫 찾기와 위치

Codex.exe 또는 ChatGPT.exe 프로세스의 작고 투명한 펫 창을 찾습니다. 펫 그림이나 특정 스킨 이름에 의존하지 않습니다. 위치는 약 0.2초마다 갱신하고 펫 창이 없어지면 다시 검색합니다. 펫을 숨기거나 최소화하면 표시줄도 숨깁니다.

표시줄은 **펫 위에 가운데 정렬**합니다. 화면 위쪽 공간이 부족하면 아래로 옮기며, 모니터 작업 영역과 디스플레이 배율을 반영합니다. 표시줄을 표시하거나 이동할 때 키보드 포커스를 가져오지 않습니다.

후보가 여러 개면 임의로 고르지 않습니다. **펫 자동으로 다시 찾기** 또는 **자동으로 찾지 못할 때 직접 선택 → 펫 선택 (3초 후)**를 누르고 마우스를 펫 몸 위에 올려두세요. 다른 앱이 만든 펫은 대상이 아닙니다. 커스텀 펫이 별도의 창 구조를 사용하면 감지되지 않을 수 있으며, 실제 설치본에서 확인이 필요합니다.

## 한도 연결

Codex 앱에 포함된 공식 연결 도구 또는 PATH의 codex.exe를 자동 검색하고 기존 로그인으로 **account/rateLimits/read**를 60초마다 조회합니다. 초기화와 한도 읽기만 요청하며 코딩 작업을 시작하지 않습니다. 앱과 연결 도구가 다른 프로필을 사용하면 표시 계정이 다를 수 있습니다.

연결 실패 시 **한도 연결 설정**에서 Codex 설치 폴더의 resources 안에 있는 연결 도구 codex.exe를 선택할 수 있습니다. ChatGPT.exe나 앱을 실행하는 Codex.exe가 아닌 Codex CLI 도구여야 합니다.

최근 사용량 기록 옵션을 켜면 연결 실패 시 로컬 Codex sessions 기록의 한도 필드를 읽습니다. 이 값은 현재 계정의 실시간 한도와 다를 수 있으므로 출처와 조회 시각을 표시합니다. 값을 확인하지 못하거나 초기화 시각이 지난 경우에는 **—**를 표시합니다.

## 이전 앱 모드에서 전환

이전 패치가 **권한 오류로 실패했다면 새 프로그램만 실행**하면 됩니다. 이전 버전에서 앱을 실제로 수정했다면 **이전 앱 모드 복원 → 원본 복원**으로 제거할 수 있습니다. 복원 전에는 Codex 앱을 트레이에서도 완전히 종료하세요. 복원 작업에만 필요하면 UAC 승인을 요청합니다.

복원 전 LocalAppData/CodexPetPlus/mod의 백업을 삭제하지 마세요. 앱 업데이트나 다른 변경으로 백업이 현재 파일과 맞지 않으면 덮어쓰기를 거부합니다. 자세한 이전 모드·백업 설명은 [이전 버전 참고 자료](desktop/LEGACY-MOD.ko.md)에 보관합니다.

## 개발과 검증

[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)를 설치하고 Windows PowerShell에서 실행합니다. SDK 버전은 global.json에 고정돼 있습니다.

~~~powershell
./desktop/Build-Windows.ps1
~~~

결과는 **dist/windows/CodexPetPlus.exe**와 **dist/CodexPetPlus-Windows-x64.zip**입니다.

코어 검사는 남은 한도 해석, 위/아래 배치, 음수 모니터 좌표, 배율, 이전 설정 전환, Codex stdio 통신과 이전 모드 복원을 검증합니다. Windows 전용 합성 창 테스트는 실제 Win32 창 감지, 커스텀 제목, 위치 추적, 위쪽 경계, 포커스 유지, 숨김·재생성 후 검색과 한도 렌더링을 확인합니다. 이 테스트는 별도의 가짜 ChatGPT.exe 호스트를 사용하며 실제 앱·계정에 연결하지 않습니다.

GitHub Actions는 Windows 빌드와 합성 창 검사를 실행합니다. 이전 모드 회귀 검사는 공식 ASAR 도구와 실제 Electron 합성 앱을 사용합니다. 실제 사용자 앱의 펫 감지와 로그인 계정의 한도 조회는 사용자 PC에서 확인해야 합니다.

이전 Chrome 확장 사용법은 [extension/README.md](extension/README.md), 개인정보 처리 범위는 [PRIVACY.md](PRIVACY.md)를 참고하세요.
