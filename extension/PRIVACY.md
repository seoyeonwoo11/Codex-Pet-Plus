# Codex Pet Plus 개인정보 처리

- 로그인은 공식 https://chatgpt.com 페이지에서 처리합니다. 확장에 비밀번호를 입력하지 않습니다.
- 로그인된 페이지의 세션 토큰은 같은 사이트의 읽기 전용 Codex 요청에 잠깐 사용합니다. 토큰이나 전체 계정 객체는 확장으로 전달·저장·로그하지 않습니다. 쿠키를 추출하지 않습니다.
- 읽는 웹 데이터는 Codex 요금제 이름, 한도 비율/기간/초기화 시각, 웹 작업 ID/제목/환경 이름/상태/갱신 시각입니다. 웹 요청은 ChatGPT로만 전송합니다.
- 데이터는 Chrome의 storage.session 메모리에만 유지하며 브라우저를 재시작하면 지워집니다. 연결 설정은 storage.local에 남습니다. 연결 해제 시 가져온 캐시를 지웁니다.
- 사용량 알림을 켜면 notifications 권한을 선택적으로 요청합니다. 알림 켜기/끄기만 로컬에 저장하고, 중복 알림 방지용 한도 단계와 초기화 시각은 storage.session 메모리에만 유지합니다. 알림에는 한도 이름과 비율만 표시합니다.
- 다른 계정의 한도를 비교해 잘못 알리지 않도록 페이지 안에서 계정 식별자를 SHA-256으로 변환한 키를 만듭니다. 원본 계정 ID나 이메일은 반환하지 않으며 이 키도 메모리에만 유지하고 외부로 보내지 않습니다.
- 로컬 파일이나 데스크톱 앱을 읽지 않습니다. Native Messaging, 쿠키 조회, 모든 사이트 접근 권한을 요청하지 않습니다. 사이트 접근은 chatgpt.com으로 제한합니다.
- 별도 백엔드, 분석/광고 도구, 원격 코드 또는 제3자 데이터 전송은 없습니다.
- 이 프로젝트는 OpenAI의 공식 제품이 아닙니다.
