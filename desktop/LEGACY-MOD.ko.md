# 이전 버전(0.4~0.5)의 앱 모드 참고 자료

이 문서는 이전 모드의 동작·백업 형식을 보관한 자료입니다. **0.6.0부터는 별도 표시줄이 기본이며 새 앱 패치를 설정 화면에서 제공하지 않습니다.** 기존 패치를 제거하려면 현재 프로그램의 **이전 앱 모드 복원 → 원본 복원**을 사용하세요. 아래의 설치 화면 설명은 이전 버전 기준입니다.

**기존 앱을 수정해 기본·커스텀 펫 아래에 남은 Codex 한도를 표시하는 비공식 모드**입니다. 설치기 0.5.0부터 앱 전체 복사본을 만들지 않습니다. 패치 후에는 평소 사용하던 앱 바로가기로 실행할 수 있으며 설치기는 종료해도 됩니다.

대상 앱 버전은 **26.1023.51421**, Windows 10/11 x64입니다. 앱 버전은 app.asar의 package.json에서 확인합니다. EXE의 브라우저 엔진 버전이나 Windows 패키지 폴더 버전을 비교하지 않습니다.

## 설치 경로의 제한

**설치 폴더에 쓰기 권한이 있어야 직접 패치할 수 있습니다.** WindowsApps에 설치된 보호 패키지는 파일 권한이나 패키지 무결성 정책으로 수정·실행이 제한될 수 있습니다. 설치기가 소유권·ACL·보안 정책을 변경하거나 권한 오류를 우회하지 않습니다. 현재 설치본에 권한이 없으면 직접 패치를 중단합니다.

ASAR 패키지와 실행 파일의 지원 형식을 검사합니다. 실제 26.1023.51421 설치본은 이 클라우드 환경에 없으므로 최종 호환성은 사용자 PC에서 확인해야 합니다.

## Windows 관리자 승인(UAC)

설치기 **0.5.1**은 권한 부족 시 Windows의 관리자 승인 창을 요청합니다. **관리자 승인으로 패치**를 누르면 바로 승인 창을 요청할 수 있습니다. 쓰기 권한 확인·패치·원본 복원 중 필요한 작업만 관리자 권한의 별도 프로세스로 실행하며, 기존 화면과 선택한 앱은 유지됩니다.

승인을 취소하면 현재 화면으로 돌아옵니다. 관리자 작업은 원래 설치기 프로세스의 Windows 사용자 데이터 폴더를 확인해 같은 백업·설치 기록을 사용합니다. 원래 사용자를 확인하지 못하면 작업하지 않습니다. 앱 실행과 한도 조회는 일반 화면에서 수행합니다. UAC는 비밀번호를 이 프로그램에 전달하지 않습니다.

**UAC 승인은 WindowsApps 파일 소유권·ACL·패키지 보호를 해제하지 않습니다.** 관리자 승인 후에도 쓰기 권한을 다시 확인하고, 보호가 남아 있으면 중단합니다. 승인 창을 띄웠다고 이 설치본에 패치를 보장하는 것은 아닙니다.

## 다운로드와 적용

1. 일반 크롬에서 GitHub에 로그인한 뒤 [Windows 빌드 페이지](https://github.com/seoyeonwoo11/Codex-Pet-Plus/actions/workflows/windows-desktop.yml)를 엽니다.
2. 최신 성공한 main 실행의 **Artifacts → CodexPetPlus-Windows-x64**를 다운로드해 압축을 풉니다.
3. **CodexPetPlus.exe**를 실행하고 상단의 **설치기 0.5.1**을 확인합니다. .NET, Node.js, Python을 별도 설치할 필요가 없습니다.
4. 자동 검색된 원래 앱의 ChatGPT.exe 또는 Codex.exe를 확인합니다. 필요하면 **찾기…**에서 선택합니다.
5. 진행 중인 작업을 마친 뒤 앱을 트레이에서도 완전히 종료합니다. **쓰기 권한 확인**으로 수정 가능 여부를 확인할 수 있습니다.
6. **앱에 패치**를 누릅니다. 권한이 부족하면 Windows 관리자 승인을 요청합니다. 승인 후 완료되면 평소 앱 바로가기 또는 **앱 실행**으로 열고 원하는 펫을 켭니다.

같은 앱의 펫 화면을 사용하는 커스텀 외형을 지원합니다. 그림이나 이름으로 매칭하지 않습니다. 외부에 따로 설치한 다른 펫 프로그램은 대상이 아닙니다. 펫 선택은 앱의 기존 기능을 사용하세요.

## 저장 공간과 복원

변경 대상은 앱의 **ChatGPT.exe/Codex.exe**와 **resources/app.asar** 두 파일입니다. 변경 전 ASAR 헤더·시작 모듈과 실행 파일에서 바뀌는 바이트만 압축해 백업합니다. DLL, 나머지 리소스, 실행 파일 전체를 백업하지 않습니다. 압축 백업의 실제 크기는 설치 완료 화면에 표시합니다.

앱 묶음을 다시 써야 하므로 **설치·복원 중에는 두 변경 파일 크기만큼의 임시 작업 공간**이 필요합니다. 화면에 예상 크기를 표시합니다. 설치·복원 작업 중에는 설치기를 종료하지 마세요.

**앱 업데이트·모드 제거 전에는 앱을 종료하고 ‘원본 복원’을 실행하세요.** 복원에 성공하면 원래 두 파일의 바이트가 동일해집니다. 백업은 LocalAppData/CodexPetPlus/mod/backups에 보관하며 복원에 필요합니다. 복원 전 백업 폴더를 삭제하지 마세요. 앱이 업데이트되거나 다른 모드로 파일이 바뀌면 덮어쓰기를 거부합니다. 파일 삭제·손상 등으로 부분 복원이 불가능하면 공식 앱의 복구·재설치가 필요할 수 있습니다.

패치 도중 중단된 경우에도 백업과 기록을 보존하고, 인식 가능한 이전/패치 상태의 파일 조합을 복원할 수 있습니다. 실행 파일 서명이 달라지므로 Windows 정책에 따라 패치된 앱 실행이 제한될 수 있습니다. 해당 정책을 해제하는 절차는 제공하지 않습니다.

이전 복사본 모드가 있다면 원본 앱에 직접 패치를 완료한 후 실행 중이지 않은 이전 복사본과 그 바로가기를 정리합니다. 사용 중인 복사본은 삭제하지 않습니다.

## 한도와 상태

표시값은 **Codex 연결 도구에 로그인한 계정의 Codex 사용 한도**입니다. 번들 도구로 account/rateLimits/read를 60초마다 조회합니다. 초기화와 한도 읽기만 요청하며 작업을 시작하지 않습니다. 앱과 도구가 다른 Codex 홈/프로필을 사용하면 계정이 다를 수 있습니다. 조회 실패·값 누락·초기화 시각 경과 시에는 **—**를 표시합니다.

펫을 이동하면 표시줄도 따라가며, 화면 아래 공간이 부족하면 위에 표시합니다. 펫을 숨기면 표시줄도 숨기고, 마우스·키보드 포커스를 가져오지 않습니다. **상태 확인**에서 펫 연결과 한도 조회 여부를 확인할 수 있습니다. 상태 파일은 사용자 폴더에 저장합니다.

## 별도 표시줄

선택 기능인 **별도 표시줄로 연결하기**도 남아 있습니다. 이 기능은 앱 파일을 수정하지 않습니다. 모드 패치 성공 시 별도 표시줄을 꺼 중복 표시를 방지합니다. 이 방식에서만 최근 JSONL 기록 사용 옵션을 제공합니다.

## 개발과 검증

[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)를 설치한 뒤 PowerShell에서 실행합니다.

~~~powershell
./desktop/Build-Windows.ps1
~~~

결과는 **dist/windows/CodexPetPlus.exe**와 **dist/CodexPetPlus-Windows-x64.zip**입니다. SDK는 global.json에 고정돼 있습니다.

~~~sh
npm run test:mod
dotnet run --project desktop/CodexPetPlus.Tests/CodexPetPlus.Tests.csproj -c Release
~~~

코어 테스트와 모드 런타임 테스트를 제공합니다. Windows에서는 원래 사용자의 폴더 확인과 다른 실행 파일의 요청 거부도 검사합니다. UAC 승인 창에 실제로 응답하는 과정과 보호된 앱 설치본은 사용자 PC에서 확인해야 합니다. 전체 복사 없는 준비, 원본 바이트 복원, 중단 상태 복구, 다른 변경 보호, 백업 손상 거부를 검증합니다. 합성 앱을 공식 ASAR 도구로 패킹해 실제 Electron에서 자동 연결·이동·숨김·커스텀 펫 재연결도 확인합니다. 합성 테스트에는 ChatGPT/Codex 소스나 계정이 들어 있지 않습니다.

실제 Electron 검증을 재현하려면 Release 코어 테스트를 먼저 빌드하고 Node.js 24에서 실행합니다.

~~~powershell
$env:PET_MOD_TOOLS = Join-Path $env:TEMP 'pet-plus-mod-tools'
npm install --prefix $env:PET_MOD_TOOLS @electron/asar@4.3.1 electron@45.1.0
node tests/run-mod-electron.mjs
~~~

Linux에서는 가상 화면이 필요합니다. PET_DOTNET_PATH로 dotnet 경로를 지정할 수 있습니다.

이전 Chrome 확장 사용법은 [extension/README.md](extension/README.md), 개인정보 범위는 [PRIVACY.md](PRIVACY.md)를 참고하세요. OpenAI의 공식 제품은 아닙니다.
