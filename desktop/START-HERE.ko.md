# Codex Pet Plus · Windows

1. Codex 앱에서 기본 펫을 켭니다.
2. 이 폴더의 **CodexPetPlus.exe**를 실행합니다. 관리자 권한이나 별도 .NET/Node/Python 설치는 필요하지 않습니다.
3. 설정 창에서 **펫 선택 (3초 후)**을 누르고, 마우스를 Codex 펫 위에 올려둡니다.
4. 펫 아래에 기본/주간 **남은 한도**가 표시됩니다. 펫을 옮기면 표시줄도 따라갑니다.

작업 표시줄 트레이의 **Codex Pet Plus** 아이콘 또는 표시줄을 우클릭하면 설정·새로고침·종료를 선택할 수 있습니다.

- **앱 연결**: Codex 로컬 app-server에서 조회한 값입니다. 앱과 같은 로컬 Codex 로그인 상태를 사용합니다.
- **최근 기록**: 조회가 안 되어 최근 사용량 기록을 표시하는 상태입니다. 현재 계정과 다를 수 있으며 기록 시각을 확인해야 합니다. 설정에서 최근 기록 사용을 끌 수 있습니다.
- **—**: 값이 없거나 초기화 시각이 지나 다시 조회해야 합니다. 0%로 추정하지 않습니다.

자동 연결이 안 되면 설정의 **연결 도구 경로**에서 Codex 설치 폴더의 resources 아래에 있는 **codex.exe**를 선택하세요. 이는 Codex 본창을 여는 실행 파일과 구분됩니다. 로컬 기록 폴더 기본값은 사용자 폴더의 **.codex**입니다.

표시줄은 별도 Windows 창으로 구현됩니다. 화면 아래 공간이 부족하면 펫 위에 표시하고, 펫이 숨겨지면 함께 숨깁니다. Codex 버전에서 펫을 독립된 작은 창으로 제공해야 위치를 따라갈 수 있습니다.

Windows 10/11 x64용입니다. 설정은 현재 사용자의 LocalAppData/CodexPetPlus/settings.json에만 저장하며, 비밀번호나 토큰을 읽거나 저장하지 않습니다. 종료하면 프로그램 폴더를 삭제해 제거할 수 있습니다.
