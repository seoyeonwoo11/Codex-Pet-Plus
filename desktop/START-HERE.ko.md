# Codex Pet Plus · 앱 모드

대상: Windows 10/11 x64, 앱 버전 **26.1023.51421**. 실제 해당 앱의 패키지는 사용자 PC에서 확인해야 하는 초기 버전입니다.

1. **CodexPetPlus.exe**를 실행합니다.
2. 자동 검색된 앱을 확인하고 **모드 설치 / 다시 설치**를 누릅니다. 못 찾으면 설치된 앱의 ChatGPT.exe 또는 Codex.exe를 선택합니다.
3. 진행 중인 작업을 마친 뒤 앱을 트레이에서도 완전히 종료합니다.
4. **모드 앱 실행** 또는 **시작 메뉴 → Codex Pet Plus**로 모드 앱을 엽니다.
5. 앱에서 기본 펫이나 원하는 커스텀 펫을 켭니다. 그 아래에 Codex 남은 한도가 자동으로 붙습니다.

설치기는 종료해도 모드 앱 안의 한도 표시가 동작합니다. .NET, Node.js, Python의 별도 설치는 필요하지 않습니다. 한도 조회가 실패하거나 기간이 만료되면 **—**로 표시합니다. 설치기의 **상태 확인**에서 펫 감지와 한도 연결 상태를 확인할 수 있습니다.

이 모드는 사용자 폴더에 만든 앱 복사본에 설치됩니다. 앱 한 벌을 복사할 공간이 필요하며, 복사본의 실행 파일 서명이 달라집니다. Windows 정책에 따라 실행되지 않을 수 있습니다. 앱 업데이트 후에는 해당 버전용 모드를 다시 설치해야 합니다.

공식 앱으로 돌아가려면 모드 앱을 종료한 뒤 기존 공식 앱 바로가기로 여세요. 제거하려면 모드 앱 종료 후 **LocalAppData/CodexPetPlus/mod**와 시작 메뉴의 Codex Pet Plus 바로가기를 삭제합니다. 인증 파일이나 비밀번호는 이 프로그램이 읽거나 저장하지 않습니다. 계정은 번들 Codex 연결 도구의 로컬 로그인 기준입니다.

별도 표시줄 옵션은 기본적으로 꺼져 있습니다. 모드와 함께 켜면 중복 표시됩니다. 기본 펫과 같은 화면을 사용하는 커스텀 펫 외형을 지원하며, 외부의 다른 펫 프로그램은 대상이 아닙니다.
