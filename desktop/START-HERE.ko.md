# Codex Pet Plus 0.5.0 · 원본 앱 패치

대상: Windows 10/11 x64, 앱 버전 **26.1023.51421**. 앱 전체 복사본을 만들지 않습니다.

1. **CodexPetPlus.exe**를 실행하고 상단의 **설치기 0.5.0**을 확인합니다.
2. 자동 검색된 원래 앱의 ChatGPT.exe 또는 Codex.exe를 확인합니다.
3. 진행 중인 작업을 마친 뒤 앱을 트레이에서도 완전히 종료합니다.
4. **쓰기 권한 확인**으로 수정할 수 있는 설치본인지 확인한 뒤 **앱에 패치**를 누릅니다.
5. 평소 앱 바로가기로 실행하고 기본 펫이나 원하는 커스텀 펫을 켭니다. 그 아래에 남은 Codex 한도가 붙습니다.

WindowsApps 보호 설치본은 권한·패키지 무결성 정책으로 직접 수정이나 실행이 제한될 수 있습니다. 쓰기 권한이 없으면 중단하며 소유권·ACL·보안 정책을 변경하지 않습니다. 실제 해당 앱 패키지의 호환성은 사용자 PC에서 확인해야 합니다.

변경 대상은 실행 파일과 resources/app.asar입니다. 변경 전 헤더·시작 모듈·실행 파일의 변경 바이트만 압축 백업합니다. 설치·복원 중에는 두 변경 파일 크기만큼 임시 공간이 필요합니다. 설치기는 작업이 끝나면 종료해도 됩니다.

**앱 업데이트·모드 제거 전에는 앱을 종료하고 ‘원본 복원’을 누르세요.** 복원 전 **LocalAppData/CodexPetPlus/mod**의 백업을 삭제하지 마세요. 앱이 업데이트되거나 다른 변경이 있으면 복원을 거부합니다. 복원이 불가능하면 공식 앱 복구·재설치가 필요할 수 있습니다. 패치된 실행 파일의 서명이 달라지므로 Windows가 실행을 제한할 수 있습니다.

.NET, Node.js, Python의 별도 설치는 필요하지 않습니다. 한도 조회 실패·값 누락·기간 만료는 **—**로 표시합니다. **상태 확인**에서 펫 연결과 한도 조회 여부를 확인하세요. 사용량은 번들 Codex 연결 도구의 기존 로그인 기준이며, 이 프로그램은 비밀번호나 토큰을 직접 읽거나 저장하지 않습니다.
