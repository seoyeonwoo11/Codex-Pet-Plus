# Codex Pet Plus 0.6.0 · 펫 위에 한도 표시

Windows 10/11 x64용입니다. 앱 수정·복사·WindowsApps 권한 변경 없이 실행합니다.

1. 이전 Pet Plus가 실행 중이면 트레이 아이콘에서 **종료**를 선택합니다.
2. 압축을 푼 새 **CodexPetPlus.exe**를 실행하고 **버전 0.6.0**을 확인합니다.
3. 평소 사용하는 Codex 앱에서 기본 펫 또는 커스텀 펫을 켭니다.
4. 자동으로 찾은 펫 위에 남은 한도 표시줄이 붙습니다. **펫 위에 한도 표시**는 기본으로 켜져 있습니다.

펫을 움직이면 따라가고, 숨기면 함께 숨깁니다. 화면 위쪽 공간이 부족하면 아래에 표시합니다. 설정 창을 닫아도 실행되며 표시줄 우클릭 또는 트레이 아이콘에서 설정·새로고침·종료를 선택합니다. 표시줄을 쓰는 동안 이 프로그램을 실행해 두세요.

찾지 못하면 **펫 자동으로 다시 찾기**를 누르세요. 후보가 여러 개면 **자동으로 찾지 못할 때 직접 선택 → 펫 선택 (3초 후)**를 누르고 마우스를 펫 몸 위에 올려두세요.

한도는 공식 Codex 연결 도구의 기존 로그인으로 조회합니다. 앱과 연결 도구의 계정·프로필이 다르면 값이 다를 수 있습니다. **한도 연결 설정**에서 연결 도구 codex.exe 경로와 최근 기록 사용 옵션을 지정할 수 있습니다. 최근 기록은 출처·시각을 표시하며 실시간 값과 다를 수 있습니다. 한도를 확인하지 못하거나 기간이 끝나면 **—**를 표시합니다.

이전 앱 패치가 권한 오류로 실패했다면 새 프로그램만 실행하면 됩니다. 실제로 패치했다면 **이전 앱 모드 복원 → 원본 복원**을 사용하세요. 복원 전에는 Codex 앱을 트레이에서도 완전히 종료하고, 복원 전까지 LocalAppData/CodexPetPlus/mod의 백업을 보관하세요. 복원에만 필요하면 관리자 승인을 요청합니다.

.NET, Node.js, Python은 별도 설치하지 않아도 됩니다. 실제 앱의 펫 감지와 계정 한도 연결은 사용 중인 PC에서 확인해 주세요. OpenAI 공식 제품은 아닙니다.
